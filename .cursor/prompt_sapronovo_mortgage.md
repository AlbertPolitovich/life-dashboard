## Бизнес-правила

### 1. Прогресс-бар ипотеки

Показывать **погашение основного долга** (не ПСК целиком):

```
прогресс = (principal_initial − principal_remaining) / principal_initial
```

- `principal_initial` = 10 595 423
- `principal_remaining` — из графика по номеру последнего **учтённого** платежа **или** пересчёт с учётом досрочных
- Полоска **заполняется** по мере внесения платежей (allocations `bucket=mortgage` с label вроде `платеж по ипотеке` + досрочные)
- Под полоской подписи:
  - **Остаток долга** · **Погашено** · **% выполнено**
  - **До конца по графику** (дата последней строки / оставшихся платежей)
  - **Переплата сверх графика** (если платил больше планового тела кредита)

**Не смешивать** в знаменателе прогресс-бара: взнос, бронь, домклик, страховку — они идут в блок **«Сопутствующие расходы»** (отдельные KPI под прогресс-баром).

### 2. Досрочное погашение (уменьшение срока)

Пользователь планирует платить **больше ежемесячно**, цель — **сократить срок**, не уменьшать платёж.

Правило банка: в месяц на досрочное погашение (уменьшение срока/долга) можно направить не более **+20% от суммы ежемесячного платежа по графику** для этой даты.

Реализация:
- В UI ипотеки — поле/подсказка **«Макс. досрочно в этом месяце: X ₽»** где `X = round(scheduled_payment * 0.2)`
- При записи платежа (allocation или форма) — валидация/предупреждение если досрочная часть > 20%
- `extra_payments_json` в `ledger_mortgage_config` — массив `{ date, amount, mode: "term" }` для пересчёта остатка вне графика (упрощённо: вычитать `amount` из `principal_remaining` после планового тела кредита за месяц)

### 3. Страховка — динамика по годам

- Отдельный мини-блок на вкладке **Ипотека**: столбцы **по годам** (2025, 2026, …) сумма страховки (`label` содержит `страховка` или отдельный `sub_label`)
- Подсветка: если сумма изменилась год к году — цвет/бейдж Δ%
- Ожидание: пока **17 906 ₽/год** — столбцы одинаковые, но UI должен быть готов к росту

## Предложение по вкладкам (ответ на вопрос «объединить со страховкой?»)

**Рекомендация: не объединять с «Разное».**

| Вкладка | Содержимое |
|---------|------------|
| **Обзор** | 4 карточки: Ипотека (прогресс) · Ремонт · Кварплата (мини-график) · Разное |
| **Ипотека** | Прогресс долга · сопутствующие расходы · страховка YoY · график/след. платёж · досрочка (+20%) |
| **Ремонт** | Одна плитка «Всего потрачено» |
| **Кварплата** | Столбцы по месяцам · ср/мед · список |
| **Разное** | Одна плитка «Всего» |

**Почему:** бронь, домклик, страховка, взнос — часть **истории кредита**; «Разное» — бытовые мелочи (приёмщик, дороги, ключи). Смешивание размывает смысл.

## Схема БД (предложение)

### Миграция `010_ledger_mortgage_schedule.sql`

```sql
CREATE TABLE ledger_mortgage_schedule (
    id              SERIAL PRIMARY KEY,
    asset_id        INT NOT NULL REFERENCES ledger_assets(id) ON DELETE CASCADE,
    payment_no      INT NOT NULL,
    due_date        DATE NOT NULL,
    payment_total   NUMERIC(12,2) NOT NULL,
    principal_part  NUMERIC(12,2) NOT NULL,
    interest_part   NUMERIC(12,2) NOT NULL,
    balance_after   NUMERIC(14,2) NOT NULL,
    UNIQUE (asset_id, payment_no)
);
```
