## Обязательные фичи (must-have в концепте)

1. **Главный экран:** текущий **баланс** (месяц / на сегодня — предложи), опционально мини-график
2. **Интуитивный ввод** дохода/расхода (минимум тапов, категории из моего списка)
3. **Распределение по категориям** — понятная визуализация (донат / bars / timeline)
4. **Напоминания по платежам** (ипотека, кварплата, подписки…) — как показать в UI
5. **Кастомные метрики:**
   - **% от общего дохода на еду** (Еда + Кафе?)
   - **Средний и медианный заработок за текущий год** (по всем источникам дохода)
   - **% дохода в активы:** 10% от (Дарья фото + Артем оклад + Артем bonus) — отдельная строка «Активы 10%»
