## Продукт — дневник (минимум как Obsidian)

Референс поведения (не стиль Obsidian):

- Календарь **текущего месяца**, сетка Пн–Вс
- Под числом — **точка**, если запись за день есть
- Тап по дате → одна заметка на день (имя `2026-06-10`)
- Содержимое — **plain textarea**, без markdown/rich text/фото
- Больше ничего: без тегов, поиска, streak, экспорта

## Deliverable 2 — код (после документа)

### Экраны

| id | Назначение |
|----|------------|
| `#diaryZoneBtn` | home-блок (вариант A или B, или оба с `?diaryHome=`) |
| `#flowDiary` | календарь месяца, точки под датами |
| `#flowDiaryEditor` | textarea + sticky «Сохранить» |

### Календарь

- Текущий месяц по умолчанию; стрелки `‹ ›` или свайп месяца (3 точки как `#nutritionDayStrip`)
- Сегодня — кольцо/фон `--link`
- Будущие дни — приглушённые; политику (кликабельны или нет) — опиши в доке и реализуй последовательно
- Под календарём: строка «Июнь · заполнено 7 из 11» (мок)

### Редактор

- Хедер: `‹` → календарь; заголовок `Сегодня · 10.06.2026` (как fill/КБЖУ)
- `<textarea>` ~60vh, placeholder «Что было важным сегодня…»
- CTA: `.cta-btn` — default / saving / success «Сохранено ✓» (как fill)
