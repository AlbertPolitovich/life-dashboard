## Словарь (простыми словами)

| Термин | Что это |
|--------|---------|
| **Фронтенд** | То, что видит человек: кнопки в Telegram, страница с графиками в браузере. |
| **Бэкенд** | «Кухня»: сохранить день, посчитать месяц, отдать JSON. Пользователь не видит код, только результат. |

| **SQL** | Язык вопросов к БД: «все дни мая», «записать 1 в сферу за 19.05». |
| **DataStore** | Договор в коде бота: подготовить день, записать routine/sport, отдать месяц. Сейчас реализация — Sheets; позже — Postgres. |
| **API** | Способ попросить программу сделать работу по сети (как сайт, но для кода). Сейчас это Apps Script у таблицы. |
| **FastAPI** | Библиотека Python для своего маленького бэкенда с API (путь B, не первый шаг). |
| **HttpStore** | Реализация DataStore: бот звонит в API, API пишет в Postgres (путь B). |
| **PostgresStore** | Реализация DataStore: бот пишет в Postgres напрямую (путь A). |
| **Docker** | «Коробка» с Postgres на Mac: поднял — база работает, выключил — не засоряет систему. |
| **Миграция (Alembic)** | Версии схемы БД: добавили поле — скрипт, а не правки руками каждый раз. |

## Три пути развития

### A. SQL у бота, сайт из таблицы *(выбрано)*

| | |
|---|---|
| **Суть** | Бот (или копия бота) пишет в Postgres; `index.html` как был — только Google Sheets. |
| **Плюс** | Учёба SQL без риска для графиков; дашборд не трогаем. |
| **Минус** | Два источника данных; истину держим: **рабочий бот + таблица**. |
| **Когда** | Сейчас. |

### B. Один посредник: API (FastAPI) + Postgres

| | |
|---|---|
| **Суть** | Отдельная программа: бот и сайт ходят в неё; она одна пишет в Postgres. Sheets убираем позже. |
| **Плюс** | Одна правда; удобно для Mini App потом. |
| **Минус** | Больше деталей: сервис, деплой, миграции. |
| **Когда** | После того как SQL «щёлкнул» на пути A. |

### C. Всё в Postgres, дашборд подождёт

| | |
|---|---|
| **Суть** | Бот + БД; браузерные графики временно без таблицы или с новым API позже. |
| **Плюс** | Быстрее отвязаться от Google. |
| **Минус** | Потеря привычных графиков на время. |
| **Когда** | Если таблица надоела сильнее, чем важен `index.html`. |

## Отдельный бот Routine/Sport_SQL — нормальная идея?

**Да, для обучения это даже удобнее**, чем сразу ломать боевой бот.

### Плюсы копии бота

- **Нулевой риск** для того бота, которым пользуетесь каждый день.
- Отдельный токен BotFather → два бота в Telegram, не путаются polling’и.
- Свой `.env`: `DATA_STORE=postgres`, другой `BOT_TOKEN`, тот же или другой `SHEETS_API_URL` (если нужен dual-write).
- Можно выкинуть эксперимент и начать снова, не откатывая git боевого бота.
- В конце **переименовать/переключить**: боевой бот получает `PostgresStore`, копию выключаете.

### Минусы (не блокеры, просто знать)

- **Два кода** на время — смягчение: **`bot/`** (прод) + **`!bot_SQL/`** (лаборатория), общие flows из `bot/`.
- **Два бота в Telegram** — не забыть, какой для жизни, какой для теста (имя в BotFather: «Life SQL test»).
- **Два источника + копия** = три слоя, если копия пишет и в SQL, и в Sheets; для учёбы можно писать **только в Postgres**, таблицу не трогать.

### Рекомендация

| Бот | Роль |
|-----|------|
| **Текущий** (life-dashboard-bot) | Прод: Sheets, напоминания, воскресные картинки. Истина. |
| **Routine/Sport_SQL** (копия) | Лаборатория: только Postgres, те же кнопки/flow, другой токен. |

Когда SQL-бот стабилен → переносите `PostgresStore` в основной бот (или меняете токен на основном) → копию архивируете.

**Проблемы «создать копию» нет** — это осознанный sandbox, не антипаттерн для новичка.

## Схема данных в Postgres (логика, не копия листа)

Не дублировать «лист = одна таблица», а разложить по смыслу:

```text
months
  id, year_month          -- например 2026-05

days
  id, month_id, date      -- одна строка на календарный день

routine_values
  day_id, sphere, value   -- 8 сфер (0/1), sphere = код сферы B..I

sport_values
  day_id, field, value    -- поля J..V (код поля: warmup, run_km, pace, …)

month_goals
  month_id, kind, target_key, value
  -- kind: fact | goal; target_key: сфера или sport_field
```

**Агрегаты для графиков** (аналог doGet `rows`, `sport`, `sportByType`):

- считать **SQL-запросами** (VIEW или методы в `PostgresStore`);
- не пересчитывать вручную в Python из сырых ячеек Sheets.

Пример связей:

```text
months 1 ── * days 1 ── * routine_values
              └── * sport_values
months 1 ── * month_goals
```

## Этапы (путь A + бот-копия)

### Фаза 0 — подготовка

- [ ] Docker Desktop (или Postgres локально).
- [ ] `docker-compose.yml` в репо: сервис `postgres`, volume для данных.
- [ ] Клиент: TablePlus / DBeaver / `psql` — смотреть таблицы глазами.
- [ ] В BotFather: второй бот, токен в `!bot_SQL/.env.sql` (не коммитить).

### Фаза 1 — база на Mac

- [ ] `db/schema.sql` или Alembic `001_initial` — таблицы выше.
- [ ] Ручные `INSERT` / `SELECT` за один день — привыкнуть к SQL.
- [ ] Скрипт `scripts/import_month_from_sheets.py` — опционально, один месяц из таблицы для практики.

### Фаза 2 — PostgresStore

- [ ] `!bot_SQL/postgres_store.py` — те же методы, что `GoogleSheetsStore` (DataStore).
- [ ] Зависимости: `asyncpg` или SQLAlchemy 2 + async (в `bot/.venv`).
- [ ] Переключение: `DATA_STORE=postgres` в `!bot_SQL/.env.sql`.

### Фаза 3 — бот Routine/Sport_SQL

- [x] Каркас: папка `!bot_SQL/` (`main_sql.py`, `postgres_store.py`, `SQL_BOT_SETUP.md`).
- [ ] Токен в `!bot_SQL/.env.sql`, запуск `python main_sql.py` из `!bot_SQL/`.
- [ ] Заполнить в SQL-боте несколько дней; проверить данные в Postgres.
- [ ] Боевой бот **не трогать** (или только вынести общий код в shared-модули без смены хранилища).

### Фаза 4 — dual-write (по желанию)

- [ ] SQL-бот пишет **и** в Postgres, **и** в Sheets (две реализации DataStore подряд).
- [ ] Сверка: один день в обоих местах совпадает.
- [ ] Или: только Postgres в SQL-боте, таблица — только через ручной импорт/экспорт раз в неделю.

### Фаза 5 — миграция в «одного» бота

- [ ] `PostgresStore` подключается к основному боту.
- [ ] Дашборд всё ещё из Sheets **или** начинается фаза B (API + смена `API_URL` в `index.html`).
- [ ] SQL-бот выключается, токен тестового бота отозвать.

### Позже (не сейчас)

- [ ] FastAPI + HttpStore (путь B).
- [ ] Telegram Mini App — форма на том же API.
- [ ] Отключить Apps Script и Sheets.
