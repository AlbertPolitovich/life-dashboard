# Карточки нормативки — МОРЕ (морские инженерные изыскания)

| Документ | О чём | Зачем |
|---|---|---|
| **СП 504.1325800.2021** | Инженерные изыскания на континентальном шельфе. Общие требования | **Главный** морской документ. Приложения по геофизике (А) и полевым методам (Б) |
| **СП 11-114-2004** | Изыскания на шельфе для морских нефтегазопромысловых сооружений | По нефтегазу (их заказчики) |
| **ГОСТ Р 59996-2022** | Морские исследования грунтов (нефтегаз, развитие ИСО 19901-8) | Геотехника на море |
| **ГОСТ Р ИСО 22476-1 / -4** | Статическое и пьезостатическое зондирование | CPT/CPTu, международная база |
| **СП 47.13330.2016** | Основные положения изысканий (общий) | База, морские СП ссылаются на него |
| **СП 446 / 502 / 317 / 482** | Сопутствующие СП по изысканиям | «В обойме» СП 504 |

---

## Связка одной фразой

> «Морские изыскания идут по **СП 504** в увязке с **СП 47.13330** и профильными СП; для нефтегаза добавляется **СП 11-114** и **ГОСТ Р 59996**; зондирование — по **ГОСТ 19912** и **ИСО 22476**.»

## Логика морского проекта (держать в голове)

**Сначала геофизика площадно «рисует» дно и разрез → потом точечно бурят/зондируют в ключевых точках → данные сшивают.**
На суше: выработки + лаборатория. На море добавляется большой слой **дистанционной геофизики** — «пешком по дну не походишь».
