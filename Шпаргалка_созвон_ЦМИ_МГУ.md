# ЧАСТЬ 2. ОСНОВЫ ПРОФЕССИИ (морские изыскания)

## 1. Из чего состоят морские инженерные изыскания

Те же 4 вида, что и на суше, + сильный блок геофизики (по **СП 504.1325800.2021**):

1. **Геодезические → на море гидрография.** Съёмка рельефа дна (батиметрия), позиционирование, поиск объектов на дне.
2. **Геологические (геотехника).** Бурение с судна, отбор пробоотборниками, полевые испытания, судовая лаборатория, статистика, ИГЭ — **здесь моё ядро почти 1:1**.
3. **Гидрометеорологические.** Волнение, течения, уровни, лёд, ветер — для нагрузок на сооружение.
4. **Экологические.** Состояние воды/донных осадков/биоты.
5. **Геофизика (сквозной блок).** Дистанционно «просвечивают» дно и привязывают к скважинам.

> **ЛОГИКА МОРСКОГО ПРОЕКТА (ключевое — понимать и сказать):**
> **Сначала геофизика площадно «рисует» дно и разрез → потом точечно бурят/зондируют в ключевых точках → данные сшивают.**
> На суше у меня выработки + лаборатория; на море добавляется большой слой **дистанционной геофизики, потому что «пешком по дну не походишь».**

## 2. Чему будут учить (морская надстройка)

| Что новое | Суть в одном предложении |
|---|---|
| **Гидрография / батиметрия** | Съёмка рельефа дна эхолотами и гидролокаторами вместо геодезии на суше |
| **Морская геофизика** | Сейсмоакустика и магнитометрия «просвечивают» дно и разрез до бурения |
| **Бурение/пробоотбор с судна** | Скважины и пробоотборники с борта/со дна, а не наземная буровая |
| **Полевые испытания на шельфе** | Статическое зондирование (CPT) как **основной** метод + крыльчатка, пьезоконус |
| **Судовая логистика** | Мобилизация судна, флот, «погодные окна», подрядчики на суда |
| **Морская нормативка** | СП 504, СП 11-114, ГОСТ Р 59996 (см. карточки ниже) |
| **Главгосэкспертиза** | Сопровождение и ответы на замечания на федеральном уровне |

> Формулировка: «Учить меня нужно морской надстройке — геофизике, гидрографии, судовой специфике и Главгосэкспертизе. Фундамент изысканий и проектную дисциплину приношу с собой.»

## 3. Карточки: нормативка по МОРЮ

| Документ | О чём | Зачем |
|---|---|---|
| **СП 504.1325800.2021** | Изыскания на континентальном шельфе. Общие требования | **Главный** морской документ. Есть приложения по геофизике (А) и полевым методам (Б) |
| **СП 11-114-2004** | Изыскания на шельфе для морских нефтегазопромысловых сооружений | Профильный по нефтегазу (их заказчики) |
| **ГОСТ Р 59996-2022** | Морские исследования грунтов (нефтегаз, развитие ИСО 19901-8) | Геотехника на море |
| **ГОСТ Р ИСО 22476-1 / -4** | Полевые испытания: статическое и пьезостатическое зондирование | CPT/CPTu на международной базе |
| **СП 47.13330.2016** | Основные положения изысканий (общий) | База, морские СП ссылаются на него |
| **СП 446 / 502 / 317 / 482** | Сопутствующие СП | Знать, что «в обойме» СП 504 |

> Связка одной фразой: «Морские изыскания идут по **СП 504** в увязке с **СП 47.13330** и профильными СП; для нефтегаза — **СП 11-114** и **ГОСТ Р 59996**; зондирование — **ГОСТ 19912** и **ИСО 22476**.»
